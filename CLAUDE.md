# Projet : refonte du portfolio Pericless

## Qui
Je suis Pericless, illustrateur, graphiste et concept artist (jeu vidéo et animation). Je suis débutant en développement web : explique-moi simplement, en français, ce que tu fais et pourquoi.

## Objectif
Un portfolio professionnel moderne et immersif pour des recruteurs, directeurs artistiques et studios de jeux vidéo. Il remplacera à terme mon site WordPress pericless.fr, qui doit rester en ligne tant que le nouveau n'est pas terminé. Ne touche jamais à ce site.

## Direction artistique
Minimaliste, moderne, dominante sombre (dark mode fixe), inspirée des portfolios de concept artists pro. Artworks en grand format, au centre de l'expérience. Animations et transitions fluides et sobres. Navigation simple.
Typographie sobre : Geist par défaut ; polices réglables par rôle avec le panneau « Typography » (polices installées copiées dans public/fonts/, licences web à vérifier). Titres en capitales espacées (styles de app/components/styles.ts) : `label` pour le haut de page (« Concept Artist & Illustrator », « Rayan Houstti », « Menu »), `titleLarge` pour le grand titre de chaque page, `titleMedium` pour les autres titres (sections, cartes, bandes, légendes). Les titres apparaissent mot par mot en fondu avec un léger bruit (BlurText). Cormorant Garamond a été retiré du projet (plus chargé dans app/layout.tsx, classe font-display supprimée de app/globals.css).

## Pages
Menu (bouton « Menu » sur tous les écrans, même style que le texte de gauche ; les liens apparaissent en fondu sous le mot « Menu », sur un voile sombre) : Concept Art, Illustration, About, Contact. Texte en haut à gauche, sur deux lignes : « Concept Artist & Illustrator » puis « Rayan Houstti » (lien vers Home). Dans app/data/site.ts : name = « Rayan Houstti » (barre du haut, pied de page, onglets, partage), title = « Concept Artist & Illustrator ».
Autres pages : Home, Projects (tous les projets, accessible depuis « View all projects »), pages détail des projets.
Concept Art : page avec 3 cartes cliquables (image 4:5 + titre), définies dans app/data/concept-art.ts : « Chara Design » (/concept-art/character-design, catégorie Character Design), « Environment » (/concept-art/environment, catégorie Environment Design), « All » (/concept-art/all, les deux). Chaque sous-page (et la page Illustration) montre ses images deux par ligne sur ordinateur, une sur mobile (ProjectBannerList : format 4:3, recadrées selon leur cadrage, titre et type par-dessus). Illustration est une catégorie à part, affichée elle aussi en bandes pleine largeur (ProjectBannerList).

## Stack
Next.js 16 (App Router, dossier app, sans src), React, TypeScript, Tailwind CSS 4, Motion pour les animations, composants 21st.dev (via shadcn), GitHub (dépôt periclessjpg/pericless-portfolio, branche main), Vercel (projet pericless-portfolio, déploiement automatique à chaque push), Visual Studio Code sous Windows (PowerShell).
