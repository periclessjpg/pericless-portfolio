ACCUEIL > IMAGE DE FOND DU HAUT DE PAGE
Glisse ici les images de fond du haut de la page d'accueil (derrière l'accroche et "Scroll to explore").
Une seule est affichée : celle choisie dans le panneau "Customize hero", sinon la première (ordre des noms).
Dossier vide : le haut de l'accueil reste noir.

RÉGLAGES (taille, transparence, zoom, flou, couleurs, voile, texte, animation, parallaxe) :
- en local (npm run dev) : bouton "Customize hero" en bas à droite de l'accueil ;
- à la main : fichier settings.json de ce dossier (expliqué dans docs/AJOUTER_MES_IMAGES.md).

CONSEILLÉ : image horizontale, jusqu'à 3840 px de large (4K), WebP ou JPG en haute qualité, idéalement moins de 3 Mo.
Avec un sujet plutôt à droite ou en haut, le texte (en bas à gauche) reste bien lisible.

CADRAGE : en mode édition local (npm run dev), clique sur "Adjust framing" sur l'image,
puis sur la partie à garder visible, et "Save". Ou, à la main, dans infos.json :
{ "01-mon-image.webp": { "position": "50% 30%" } }

Ce fichier LISEZ-MOI.txt est ignoré par le site : tu peux le laisser ici.
